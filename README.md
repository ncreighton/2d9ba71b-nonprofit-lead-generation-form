WordPress plugin providing nonprofit-optimized donation forms, volunteer signup forms, and grant inquiry lead generation. Features customizable multi-step donation forms with recurring giving options, Stripe and PayPal Nonprofit rate integration, volunteer opportunity listings with availability scheduling, grant eligibility pre-screening questionnaires, donor management dashboard with lifetime giving history, automated tax receipt generation, peer-to-peer fundraising campaign pages, event registration with donation ask, and CRM export to Salesforce Nonprofit Success Pack and HubSpot. == Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate via WordPress admin > Plugins
3. Configure via Settings > Nonprofit Lead Generation Form Builder Plugin
